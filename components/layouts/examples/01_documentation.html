Documentation Layout

Overview

The documentation layout is designed for technical content with a persistent sidebar navigation. It adapts from a two-column layout on desktop to a stacked layout on mobile with a collapsible sidebar.

Usage

Apply the .documentation-layout class to your body or a wrapper div. The structure requires:

  • .documentation-layout__header - Optional header
  • .documentation-layout__content - Wrapper for sidebar + main
  • .documentation-layout__sidebar - Navigation sidebar
  • .documentation-layout__main - Main content area
  • .documentation-layout__footer - Optional footer

Example Code

<body class="documentation-layout">
  <header class="documentation-layout__header">...</header>
  <div class="documentation-layout__content">
    <aside class="documentation-layout__sidebar">...</aside>
    <main class="documentation-layout__main">...</main>
  </div>
  <footer class="documentation-layout__footer">...</footer>
</body>

Responsive Behavior

Desktop (≥1024px): Two-column layout with fixed-width sidebar

Tablet (640px - 1023px): Two-column with narrower sidebar (200px)

Mobile (≤639px): Stacked layout with collapsible sidebar (max-height toggle)
